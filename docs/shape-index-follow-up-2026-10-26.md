## 校验后再分配已知大小的索引表

此前 shape 在扫描 shard 长度时持续收集前 k 个有效索引。超过内联 32 项后，
SmallVec 按增长策略扩容；65 个 survivor 可能先申请 64 项，再扩至 128 项。
如果后续 present shard 长度错误或最终 quorum 不足，这些有效索引堆空间也已经申请。

现在扫描阶段仅保留现有 32 项内联容量内的 survivor 前缀，同时继续收集完整的有序
缺失索引、检查每个 present 长度。所有长度通过后才判断 quorum；不足则直接返回。
验证成功且 k>32 时，一次预留恰好 k 项容量，从前缀末尾之后的缺失索引补集补齐
survivor。最终仍为原来的升序前 k 个 present shard。

补齐只遍历整数索引，不再读取 shard 长度或 payload，也没有引入 bitmap、第二张
索引表、unsafe、新 API 或缓存。窄布局无需补集后缀遍历；全 present 快路径保持。
缺失索引表的大小事先未知，其原增长策略保留。

运行时只修改 fill_classic_reconstruct_shape_from_suffix。所有实际调用者原本都会在
形状构造后完成计划/quorum 校验，因此将 quorum 判断提前到完整长度扫描之后，
保持公共错误顺序和输出状态；planner 对手工构造 shape 的 quorum 检查仍保留。
复用布局验证、目标选择、逆矩阵/缓存、组合系数、执行器、矩阵与原生内核均未变化。

头部、中部、稀疏缺失的完整恢复结果相同：

| data | 准备：此前 → 当前 | 普通完整调用：此前 → 当前 |
| --- | ---: | ---: |
| 4、32 | 0 / 0 → 0 / 0 | 0 / 0 → 0 / 0 |
| 33 | 1 / 512 → 1 / 264 | 2 / 1,040 → 2 / 792 |
| 64 | 1 / 512 → 1 / 512 | 2 / 1,536 → 2 / 1,536 |
| 65 | 2 / 1,536 → 1 / 520 | 3 / 2,576 → 2 / 1,560 |
| 96 | 2 / 1,536 → 1 / 768 | 3 / 3,072 → 2 / 2,304 |

尾部缺失的此前路径通常只扩容一次：65 data 的准备从 1 / 1,024 变为 1 / 520，
96 data 从 1 / 1,024 变为 1 / 768；对应普通调用从 2 / 2,064 变为 2 / 1,560，
以及 2 / 2,560 变为 2 / 2,304。4/32/33/64 data 与上表相同。
全 present 在所有构建、目标和宽度均为 0 / 0。

合法无输出目标仍持有可验证的 shape，准备与普通调用的成本都等于上述准备列，
不能称为所有请求零分配。

以下非法布局中，缺失索引未超过内联容量；准备、普通调用及两个目标的结果相同：

| data | 末尾短/空长度：此前 → 当前 | quorum 不足：此前 → 当前 |
| --- | ---: | ---: |
| 4、32 | 0 / 0 → 0 / 0 | 0 / 0 → 0 / 0 |
| 33 | 1 / 512 → 0 / 0 | 0 / 0 → 0 / 0 |
| 64 | 1 / 512 → 0 / 0 | 1 / 512 → 0 / 0 |
| 65 | 2 / 1,536 → 0 / 0 | 1 / 512 → 0 / 0 |
| 96 | 2 / 1,536 → 0 / 0 | 2 / 1,536 → 0 / 0 |

quorum+短长度的申请量与 quorum 列相同，返回值仍为长度错误。4+97 的四个宽缺失
布局保持 2 / 1,536 的准备成本；成功完整恢复另有一张输出表，总计 3 / 2,056。
失败或无输出仍保留缺失索引申请，不能把这里的错误路径结果推广为全局零分配。

补集后缀会增加一次有限的整数索引遍历，其大小取决于 k-32 和跨过的 erasure 数。
本轮没有稳定耗时证据，不能从申请减少推导端到端速度提升；历史 ABBA 漂移失败记录保留。

## 后续执行顺序

下一步先评估“补集遍历与分配减少”的稳定耗时及真实布局频率，再决定更广的 shape
复用或无输出形状表示。缺失索引容量仍需结合 erasure 分布验证；直接预留 parity
上限可能扩大稀疏和非法请求的内存，当前不据此调整。

普通 verify 分块仍需生产瓶颈、大小/并发分布和 scratch 预算；Leopard oversized
缓存策略仍需线程/大小分布及峰值预算；算术与并行阈值继续等待稳定测量环境。
本轮仅提交本地实现与证据，未 push、创建 PR、打 tag 或发布 crate。
