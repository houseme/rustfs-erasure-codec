# Borrowed missing targets for Classic recovery

Runtime `7bf62d5` is based on main `e758f11`. The
[complete resource and compatibility result](../benchmarks/release-9.1.0/2026-10-25/borrowed-recovery-targets.json)
contains every one of the 54 before/after controls and the source boundaries.

The validated erasure shape already owns all missing indices in order. Ordinary
All/Data recovery previously copied its data and parity portions into two more
target lists. The new plan borrows those portions directly. One split count keeps
data and parity iteration in the original order; Data goals expose no parity
outputs. Target accessors serve generic, bulk/workspace and stream execution.

Required goals still own a filtered, ordered selection, independent of caller
request flags. One optional 64-index list replaces the two 32-index lists and is
filled in its final storage. If both former lists fit inline, their combined
selection still fits inline. A tested size bound covers the replaced index
storage; it does not claim a measured whole-function stack-frame reduction.
Matrix rows, inverses/cache keys, field arithmetic, native selection, policy
budgets, validation priority and output publication remain unchanged. No public
API, format, option, unsafe operation or shape-specific heuristic is added.

## Executed resource and compatibility checks

The public-API regression fails on unmodified main `e758f11`: all 54 cases record
five caller-thread allocation requests per operation. The new source records four
in every case. Coverage is GF8/GF16, Vandermonde/Cauchy/JerasureLike, 33+33 / 40+40 /
64+64 shapes, and All-data / Data-only / All-parity recovery. Caller ShardSlot
buffers have 65 elements, inverse/backend setup is warmed outside the measured
call, and recovered bytes/present flags are exact. This is allocation accounting
for these generic entry points, not throughput, parallel/Option-vector allocation,
RSS or an explanation of historical page faults.

Borrow-identity tests verify ordinary target slices come from the canonical
shape. Selective results remain exact after caller flags change. Combined inline
capacity and the replaced metadata size are checked. Existing complete small-mask,
custom singular/general-field, selective output, late failure, concurrency,
workspace and streaming regressions pass.

Stable local validation passes:

- 397 library, 165 integration and ten doc parent tests (572); six filtered child
  executions are counted separately; 43 existing ignored remain unchanged.
- Codec-only no_std: 268 tests. Rust tooling: 278 unit and 39 CLI (317), with strict
  codec/tool Clippy, formatting, spelling and diff checks.
- Published 9.0.0 on the local default backend: 200 non-fast normal configurations,
  27 custom / 162 cross recoveries, 12 wide GF16 configurations and 270 selective /
  2,640 cross recoveries, retaining exact bytes and bidirectional recovery.
- Fresh release WASM generation, TypeScript and all 14 Node cases pass (12 actual
  module cases, one result-code contract, one facade unit; zero skipped).
- x86 Darwin all-target and x86 Linux library strict Clippy pass as compile-only
  checks. Linux all-target cross compilation encounters the absent cross C compiler
  for the benchmark-only alloca dependency; that original environment failure is
  retained. It is not presented as a passing gate or Linux runtime execution.

The local reports bind all tested source/test/tool bytes to the committed runtime.
Three observer families are independently compared (9 dynamic, 4 stream-core and
3 verify-scratch generated members). Reversing only the production target-accessor
calls restores every old generated byte; only reconstruct/stream consumers change.
Current-source snapshots are updated after this comparison. Frozen templates,
benchmark inputs, observation rules and acceptance thresholds are untouched.

## Native and release boundary

This runtime has not executed on Linux. Earlier source `4aa4ee0` retains its own
eight completed native commands, real foreign-process refusal and safely restored
closed lease. Its unlaunched 26-command continuation remains separate. Those
results do not qualify this changed source. Source-bound native validation and
accepted full performance evidence are still required.

The allocation improvement is deterministic resource evidence with zero timing
observations. Complete accepted published-9.0.0 ABBA/paired-layout data, final
source/tool/lock freezing and actual strict positive preflight remain outstanding.
No earlier refusal is erased, and no release approval, tag or registry upload is
produced.
